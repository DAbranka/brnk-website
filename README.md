# brnk-website

Personal website for BRNK® - a modern, interactive web experience showcasing creative work and portfolio.

🌐 **Live Site:** [brnk-website.vercel.app](https://brnk-website.vercel.app)

## Technologies Used

### Core Framework
- **Vue 3** - Progressive JavaScript framework with Composition API
- **Vite** - Next-generation frontend build tool for fast development
- **Vue Router** - Official routing library for Vue.js applications

### Styling & UI
- **UnoCSS** - Instant on-demand atomic CSS engine

### Animations & Interactions
- **GSAP** (GreenSock Animation Platform) - Professional-grade JavaScript animation library
- **Rellax** - Lightweight parallax library
- **Medium Zoom** - Image zoom library for enhanced media viewing

### Development Tools
- **ESLint** - JavaScript linting with Vue-specific rules
- **Prettier** - Code formatting
- **pnpm** - Fast, disk space efficient package manager

### Deployment
- **Vercel** - Cloud platform for static sites and serverless functions

## Recommended IDE Setup

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (and disable Vetur) + [TypeScript Vue Plugin (Volar)](https://marketplace.visualstudio.com/items?itemName=Vue.vscode-typescript-vue-plugin).

See [Vite Configuration Reference](https://vitejs.dev/config/).

## Project Setup

```sh
pnpm install
```

### Compile and Hot-Reload for Development

```sh
pnpm dev
```

### Compile and Minify for Production

```sh
pnpm build
```

### Lint with [ESLint](https://eslint.org/)

```sh
pnpm lint
```
